# Maria Andrade — Portfólio

Portfólio profissional desenvolvido para apresentar minha trajetória, experiências, habilidades técnicas e projetos na área de Tecnologia.

O projeto foi desenvolvido com foco em **Software Engineering, DevOps, Cloud e desenvolvimento Backend**, utilizando tecnologias web modernas e uma interface responsiva.

🌐 **Portfólio:** [mariaandrade-25.github.io](https://mariaandrade-25.github.io)

---

## 👩‍💻 Sobre o projeto

Este projeto representa meu portfólio pessoal e profissional, reunindo informações sobre minha trajetória de transição para Tecnologia, experiências, conhecimentos técnicos e projetos desenvolvidos durante minha formação.

A proposta é apresentar minhas habilidades de forma objetiva, com uma interface moderna, responsiva e inspirada em ambientes de desenvolvimento e infraestrutura.

## ⚙️ Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/MariaAndrade-25/MariaAndrade-25.github.io.git
```

Entre na pasta:

```bash
cd MariaAndrade-25.github.io
```

Depois, basta abrir o arquivo:

```text
index.html
```

no navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para executar o projeto localmente.
