## 📌 Como Adicionar no LinkedIn

### Método 1: Adicionar na Seção "Sobre" (Recomendado)

1. Vá para seu perfil no LinkedIn
2. Clique em **"Editar Perfil"**
3. Procure pela seção **"Sobre"**
4. Clique em **"Adicionar seção"** → **"Website"**
5. Selecione o tipo: **"Portfólio"** ou **"Site Pessoal"**
6. Cole o link:
   ```
   https://mariaandrade-25.github.io
   ```
7. Clique em **"Salvar"**

### Método 2: Adicionar no Campo "Website" do Perfil

1. Edite seu perfil
2. Procure por **"Websites e Blogs de Contato"**
3. Clique em **"Adicionar website"**
4. Selecione o tipo: **"Portfólio"**
5. Cole:
   ```
   https://mariaandrade-25.github.io
   ```
6. Salve

## ✨ Se ainda não funcionar:

### Opção A: Usar o LinkedIn Post Inspector

1. Acesse: https://www.linkedin.com/post-inspector
2. Insira seu link:
   ```
   https://mariaandrade-25.github.io
   ```
3. Clique em **"Inspecionar"**
4. Isso força o LinkedIn a "raspar" as meta tags

### Opção B: Compartilhar como Post no LinkedIn

Se ainda assim não funcionar, compartilhe assim:

1. Vá para a home do LinkedIn
2. Clique em **"Iniciar uma publicação"**
3. Cole o link:
   ```
   https://mariaandrade-25.github.io
   ```

4. Espere aparecer a preview
5. Adicione um caption:

6. Publicar!
